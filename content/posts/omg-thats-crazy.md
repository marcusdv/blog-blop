### Como escrever Markdown

Você pode usar:

- `#` para título
- `##` para subtítulo
- `*texto*` ou `_texto_` para itálico
- `**texto**` para negrito
- `-` para listas
- `![texto alternativo](url-da-imagem)` para imagens
